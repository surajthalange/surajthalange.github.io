Service

LMS Health Check

A fixed-price audit for sites running Moodle™ software.

Email surajthalange18@gmail.com → All services

I'm Suraj Thalange, an independent LMS developer and technical project manager based in India. I build and maintain learning platforms on the Moodle™ platform and custom software in Laravel and PHP, and I have upgraded sites across versions 3.7 to 5.2.

Why now: security support for the 4.5 LTS release ends on 4 October 2027. Many sites are already on releases with no security fixes. Before you upgrade, you need to know what will break.

What you get

  • Current version and security-support status
  • Full inventory of plugins, themes and custom code, each marked ready, needs work, or replace
  • Server check: PHP, database and web server versions against the target release
  • Security configuration review (admin settings, roles, exposed files, outdated components)
  • Performance basics: cron, caching, slow pages, database size
  • Backup and restore readiness
  • A written report in plain language with priorities: fix now, fix before upgrade, nice to have
  • A 30-minute call to walk through the findings
  • A fixed upgrade quote with a clear exclusions list, so there are no surprises later

How it works

  1. You send a short form: site URL, version, hosting type.
  2. You give me read-only admin access and, if possible, server access or a copy of the plugin list.
  3. I deliver the report within 5 business days.
  4. We talk, and you decide what to do next. No obligation.

Price

USD 300, fixed, paid upfront.
If you book the upgrade within 30 days, USD 150 of this fee comes off the upgrade price.

Who this suits

Training providers, schools, colleges and awarding bodies that run their own site and want a clear, costed path to a supported release.

Get started

Email me at surajthalange18@gmail.com with your site URL and current version. I reply within one business day.
