LMS Care Plan

Monthly maintenance for sites running Moodle™ software.

Email surajthalange18@gmail.com → Start with a health check

I'm Suraj Thalange, an independent LMS developer and technical project manager. I've built, upgraded and supported learning platforms from small training sites to a 250,000-user government platform, and I build custom software in Laravel and PHP. The Care Plan keeps your site secure and up to date without you having to think about it.

Every month

  • Security and minor-release updates, tested on staging first
  • Plugin and theme updates
  • Monthly health snapshot: version status, errors, cron, disk and database growth
  • Backup check (we confirm a restore works, not just that a file exists)
  • A short written report
  • Support hours for fixes, small changes and admin questions
