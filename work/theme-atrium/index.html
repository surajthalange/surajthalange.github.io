Work / Theme

theme_atrium

A complete Boost child theme for Moodle 5.1 and 5.2. Every page an administrator, teacher or learner sees is designed, every feature is a setting, and every feature has a test.

northbridge.learning

Why I built it

Most Moodle sites either run stock Boost or buy a commercial theme that brings a page builder, external requests and a support dependency. Atrium is the third option: a theme that gives an administrator a designed site through Moodle's own settings pages, fetches nothing from outside the site by default, and is testable the way core is. I studied the feature lists of commercial themes to decide what a "whole theme" must cover, then designed and wrote Atrium's own implementation of each.

How it is built

  • Boost child theme. Layouts and templates are overridden only where the design needs it; an override register in the README lists every one, so upgrades can be checked against it.
  • Settings are typed models with their own unit tests, not raw get_config calls scattered through templates.
  • Per-user state (dismissed announcements, focus mode, grid or list view, accessibility choices) uses core user preferences and is rendered server side.
  • No page builder. Fonts are bundled, and the theme makes no request to any outside service unless Google Analytics 4 is switched on, in which case the setting says so and site administrators are excluded.
  • Mustache templates follow core's conventions: strings through {{#str}}, no inline scripts, ARIA via core helpers.

GitHub Actions runs the Moodle plugin CI suite on every push: phplint, phpcs with the Moodle standard, phpmd, phpcpd, PHPDoc checker, Mustache lint, Grunt build check, savepoints, PHPUnit and Behat, across a matrix of Moodle 5.1 and 5.2, PHP 8.2 to 8.4, and both databases. PHPUnit covers the settings models, catalogue and enrolment data, announcement hashing, quick links parsing and preference handling. Behat covers every page a user interacts with: front page sections, catalogue search and view toggle, enrolment for guest, self and fee, focus mode, announcement dismissal, quick links, profile and the login layouts.

What it costs the page

Measured on one site with every theme at its defaults, as the browser receives it: Atrium’s compiled stylesheet is 199 KB gzipped, against core Boost’s 175 KB and Moove’s 318 KB. So about 23 KB more than stock Moodle for everything above, and roughly a third smaller than the most-installed free theme. Both bundled typefaces are served by the site, so nothing is fetched from another host. The method is published in the repository, and no claim is made about render speed, which was not measured.
